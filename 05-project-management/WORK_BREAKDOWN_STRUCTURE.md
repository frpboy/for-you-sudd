# Work Breakdown Structure

**Project:** Our Story - Mobile Birthday Experience  
**Status:** Baseline v1.0  
**Target date:** 8 August 2026  
**Document purpose:** Decompose the project into assignable, testable work packages.

> Confirmed client facts are marked **Confirmed**. Missing personal content is marked **Client input required**. Optional ideas are marked **Enhancement**.


## 1. Product and content

1.1 Confirm facts and names. 1.2 Approve journey and P0. 1.3 Inventory media. 1.4 Approve letter/memories/reasons/dreams. 1.5 Approve music rights. 1.6 Sign content freeze.

## 2. Platform foundation

2.1 Repository/CI. 2.2 TypeScript/lint/test/build. 2.3 Tokens and layout. 2.4 UI primitives. 2.5 Content schema/loader. 2.6 Story reducer. 2.7 Error boundaries. 2.8 Synthetic fixtures.

## 3. Privacy and media

3.1 Threat model. 3.2 Access/session. 3.3 Protected media delivery. 3.4 Headers/robots/metadata. 3.5 Image pipeline. 3.6 Video pipeline. 3.7 Audio pipeline/coordinator. 3.8 Repository/log audit.

## 4. Experience features

4.1 Start/audio consent. 4.2 Welcome/countdown. 4.3 Timeline. 4.4 Gallery. 4.5 Video. 4.6 Voice. 4.7 Quiz. 4.8 Letter. 4.9 Cake/gift/finale. 4.10 Replay/progress. 4.11 Optional memories/reasons/dreams.

## 5. Quality and release

5.1 Unit/component/E2E. 5.2 Accessibility. 5.3 Performance. 5.4 Device/browser. 5.5 Privacy/security. 5.6 UAT. 5.7 Production/DNS/TLS. 5.8 Rollback drill. 5.9 Launch. 5.10 Retirement.
