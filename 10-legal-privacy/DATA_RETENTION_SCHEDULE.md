# Data Retention Schedule

**Project:** Our Story - Mobile Birthday Experience  
**Status:** Baseline v1.0  
**Target date:** 8 August 2026  
**Document purpose:** Assign owners and deletion dates to every copy of personal content.

> Confirmed client facts are marked **Confirmed**. Missing personal content is marked **Client input required**. Optional ideas are marked **Enhancement**.


| Data location | Content | Owner | Retain until | Deletion method | Verification |
|---|---|---|---|---|---|
| Original intake archive | Original personal media | Project owner | Client-approved date | Secure delete/archive removal | Inventory check |
| Working derivatives | Optimized assets/posters | Media owner | Project close | Delete working folders | Checksum list |
| Repository | Code; no personal media by default | Repo owner | Per project policy | Archive/delete repository | Access review |
| Preview deployments | Approved personal content | Release owner | Immediately after close/UAT | Delete deployments | Clean URL test |
| Production | Final content/media | Release owner | Agreed retirement date | Remove aliases/deployment/storage | Unauthenticated check |
| Transfer links | Intake/export packages | Sender/owner | As soon as received | Revoke/delete | Link check |
| Test evidence | Screenshots/videos | QA owner | Project close | Delete private evidence | Evidence index |
| Backups/versions | Copies in provider storage | Account owner | Provider/policy date | Delete versions where possible | Provider audit |
