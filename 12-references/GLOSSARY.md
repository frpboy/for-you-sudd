# Glossary

**Project:** Our Story - Mobile Birthday Experience  
**Status:** Baseline v1.0  
**Target date:** 8 August 2026  
**Document purpose:** Standardize terminology across client, product, engineering, and AI-agent documents.

> Confirmed client facts are marked **Confirmed**. Missing personal content is marked **Client input required**. Optional ideas are marked **Enhancement**.


| Term | Meaning |
|---|---|
| P0 | Required for safe launch; release-blocking. |
| P1 | Valuable but cuttable after P0 stability. |
| P2 | Optional enhancement; first to defer. |
| Narrative lock | Romantic quiz-style question; not security. |
| Access gate | Real server/managed protection that controls content delivery. |
| Story shell | Single runtime route/state machine containing the journey. |
| Foreground media | Video or voice note that takes priority over music. |
| Media manifest | Validated record of assets, derivatives, metadata, approval, and checksum. |
| Synthetic fixture | Non-personal test content used in code/CI. |
| Safe progress | Non-sensitive local marker for the current section/question. |
| Protected preview | Non-production deployment requiring authorization. |
| Retirement | Removal of domain, deployments, storage, previews, secrets, and working copies. |
| UAT | Client validation of accurate content and intended experience. |
