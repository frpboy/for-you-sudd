# Device and Browser Matrix

**Project:** Our Story - Mobile Birthday Experience  
**Status:** Baseline v1.0  
**Target date:** 8 August 2026  
**Document purpose:** Specify required real and emulated coverage.

> Confirmed client facts are marked **Confirmed**. Missing personal content is marked **Client input required**. Optional ideas are marked **Enhancement**.


## Required real devices

- One current iPhone on Safari, portrait, sound on/off, reduced motion.
- One current/mid-range Android phone on Chrome, portrait, sound on/off.

## Required emulation/viewports

320x568, 360x800, 375x812, 390x844, 412x915, 430x932, tablet portrait, desktop 1440 width. Test touch emulation, keyboard input, slow 4G, offline transitions, and landscape.

## Browsers

Tier 1 current Safari iOS and Chrome Android. Tier 2 desktop Safari/Chrome/Edge/Firefox. In-app browsers receive a smoke test for access, start/audio, navigation, and opening in an external browser if necessary.

Record exact OS/browser versions and build/deployment ID with evidence.
