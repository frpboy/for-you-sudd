# Music Selection and Rights Brief

**Project:** Our Story - Mobile Birthday Experience  
**Status:** Baseline v1.0  
**Target date:** 8 August 2026  
**Document purpose:** Guide soundtrack selection while protecting emotional focus, performance, and copyright compliance.

> Confirmed client facts are marked **Confirmed**. Missing personal content is marked **Client input required**. Optional ideas are marked **Enhancement**.


## Recommended release approach

Use one rights-cleared instrumental track for the P0 release. A multi-track cinematic sequence is optional only after stable audio coordination and rights verification.

## Desired character

Soft piano or acoustic instrumentation, warm and intimate, minimal percussion, no distracting lyrics, clean loop point, and enough dynamic range for the final reveal without overpowering voice/video.

## Approval fields

Track title, creator/source, license type, proof/receipt URL or document, allowed web use, attribution requirement, edit/loop permission, expiry/territory, file delivered, chosen start volume, loop, and fade behavior.

## Do not ship

Commercial film/music tracks merely because the website is private. Private sharing does not automatically grant reproduction/public performance rights. Client preference can be recorded, but the release uses only an authorized file.

## Audio behavior

Start after explicit tap, visible mute, pause/duck for video and voice, restore previous user state, and fade rather than abruptly switch. The complete experience must work silently.
