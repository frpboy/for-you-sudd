# Agent Handoff Template

**Project:** Our Story - Mobile Birthday Experience  
**Status:** Baseline v1.0  
**Target date:** 8 August 2026  
**Document purpose:** Provide a consistent, lossless transition between agents and reviewers.

> Confirmed client facts are marked **Confirmed**. Missing personal content is marked **Client input required**. Optional ideas are marked **Enhancement**.


```text
Task ID / branch / commit:
Objective completed:
Requirement IDs:
Files added/modified/deleted:
Public interfaces introduced or changed:
Data/schema changes:
Environment/configuration changes:
Dependencies added/removed:
Tests and exact results:
Manual device/viewport checks:
Screenshots/evidence location:
Privacy/security observations:
Accessibility observations:
Performance observations:
Known limitations and deferred items:
Unresolved decisions:
Recommended next task and prerequisites:
How to revert safely:
```

Do not include personal letter text, access secrets, private media links, or sensitive screenshots in a broadly visible handoff.
