# Copy Deck and Content Tone

**Project:** Our Story - Mobile Birthday Experience  
**Status:** Baseline v1.0  
**Target date:** 8 August 2026  
**Document purpose:** Provide approved baseline UI copy while separating placeholders from personal writing.

> Confirmed client facts are marked **Confirmed**. Missing personal content is marked **Client input required**. Optional ideas are marked **Enhancement**.


## Tone

Intimate, sincere, calm, and specific. Avoid exaggerated promises, possessive language, manipulative quiz feedback, public-facing marketing language, and generic AI sentiment.

## Confirmed copy

- Hero greeting: “Happy Birthday to the most special person in my life!”
- Dream destination answer: “Switzerland.”
- Finale concept: “The End? No. Just Chapter One.” (requires client approval before use.)

## Baseline interface copy

| Context | Copy |
|---|---|
| Loader | Loading our memories… |
| Entry label | One question before we begin… |
| Entry question | What is our dream destination? |
| Incorrect entry | Not quite. Try once more. |
| Start | Tap to begin |
| Sound disclosure | This story includes music and voice. You are always in control. |
| Primary CTA | Begin our story |
| Gallery error | This memory did not load. Retry or continue. |
| Quiz success | Exactly. You remember us. |
| Quiz retry | Almost. Try again. |
| Voice note | A message from me |
| Letter heading | A letter for you |
| Cake fallback | Tap the candle |
| Gift fallback | Tap to open |
| Replay | Read our story again |

## Placeholder rules

Use visible tokens such as `{{recipient.displayName}}`, never invented names. All emotional paragraphs, reasons, memories, captions, and future claims require client approval. AI may edit supplied notes for clarity only when the client reviews the final text.
