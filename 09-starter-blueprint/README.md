# Starter Blueprint

This directory is a reference implementation skeleton, not a finished personalized website. It encodes the architectural decisions and safe defaults so AI agents can initialize the real private repository consistently.

1. Create a new Next.js App Router project using the current supported patched release.
2. Apply the example configs after verifying current official versions.
3. Copy `AGENTS.md` to the repository root.
4. Implement content schema and synthetic fixtures before personal content.
5. Select the protected media strategy before adding real assets.
6. Keep all personal files outside public Git history.
